Digitale Formulare, die Prozesse starten

Daten dort erfassen, wo sie entstehen

Ein Formular entsteht direkt aus Ihrem Grid und lässt sich in Minuten teilen – am Fahrzeug, an der Maschine, beim Kunden oder auf Ihrer Website. Jede Antwort landet als Eintrag in Ihrer Datenbank und kann von dort einen Workflow auslösen. Ein digitales Formular ist damit kein Einzelstück, sondern der Anfang eines Geschäftsprozesses.

Aufbauen

Formulare digitalisieren, ohne bei null anzufangen

Der Formular-Builder arbeitet auf Ihrer Datenbank statt auf einem leeren Blatt: Sie wählen die Felder aus, die abgefragt werden sollen, und benennen sie so, wie die ausfüllende Person sie versteht. Neue Felder legen Sie direkt aus dem Formular heraus an. Der Rest des Grids bleibt unsichtbar.

  • Felder auswählen — vorhandene Spalten übernehmen oder neue anlegen
  • Eigene Beschriftungen — „Kennzeichen“ für außen, „fahrzeug_id“ für innen
  • Passende Komponenten — Auswahllisten, Mehrfachauswahl, Datei-Upload, Unterschrift
  • Pflicht und Kür — Pflichtfelder erzwingen, was nötig ist – der Rest bleibt optional

Link, QR-Code oder eingebettet

Mit „Link erstellen“ entsteht ein Freigabelink, den jede Person ohne Konto öffnen kann. Denselben Link können Sie als QR-Code drucken oder das Formular als iframe in Ihre Website einbetten – die Antworten laufen überall in dasselbe Grid.

  • Freigabelink — per E-Mail, Messenger oder Intranet verteilen
  • QR-Code — am Fahrzeug, an der Maschine, auf dem Aushang – Handy drauf, ausfüllen, fertig
  • Einbettung — als iframe im eigenen Auftritt, im Layout Ihrer Website
  • Vorausgefüllter Link — Gerät, Standort oder Ansprechpartner stehen beim Öffnen schon drin

Nach dem Absenden startet der Folgeprozess

„Eintrag per Formular“ ist einer der sechs Auslöser für einen Flow. Damit wird aus dem digitalen Formular ein automatisierter Geschäftsprozess: benachrichtigen, weiterleiten, in andere Systeme schreiben – oder auf eine Freigabe warten.

  • Sofort benachrichtigen — E-Mail, Slack, MS Teams oder SMS an die zuständige Person
  • Daten anreichern — Eintrag aktualisieren, verknüpfen oder per HTTP-Anfrage weitergeben
  • Freigabe einholen — eine Seite als Flow-Schritt hält den Prozess an, bis jemand entschieden hat
  • Belege erzeugen — PDF, QR-Code oder Kalendereintrag aus den erfassten Daten

FAQ

Fragen zu Formularen

Brauchen die Leute, die mein Formular ausfüllen, ein Konto?

Nein. Ein Formular wird über einen Freigabelink geteilt und lässt sich ohne Anmeldung ausfüllen – per Link, QR-Code oder eingebettet auf Ihrer Website.

Wohin gehen die Antworten?

Jede Antwort wird zu einem Eintrag in dem Grid, aus dem das Formular gebaut ist. Damit steht sie sofort in allen Ansichten, Auswertungen und Automatisierungen zur Verfügung.

Kann ich Felder vorbelegen?

Ja, auf zwei Wegen: als fester Standardwert im Formular oder über einen vorausgefüllten Link, der die Werte mitbringt. So steht bei einem QR-Code an einer Maschine schon drin, um welche Maschine es geht.

Lassen sich Fotos, Dateien und Unterschriften erfassen?

Ja. Dateifelder nehmen Fotos und Dokumente direkt vom Handy entgegen, es gibt Videoaufnahme, und ein Unterschriftsfeld erfasst die Unterschrift auf dem Gerät.

Kann nach dem Absenden automatisch etwas passieren?

Ja. „Eintrag per Formular“ ist einer der sechs Flow-Auslöser. Der Flow kann benachrichtigen, Daten in andere Systeme schreiben oder eine Freigabe einholen.

Was ist der Unterschied zu einer Seite?

Ein Formular ist auf schnelle Erfassung ausgelegt. Eine Seite gibt Ihnen freies Layout: Text, eingebettete Ansichten, Auswertungen und Eingabefelder zusammen – und sie kann als Schritt in einem Flow auf eine Entscheidung warten.
